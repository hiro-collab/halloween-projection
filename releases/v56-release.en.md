# Halloween Projection v0.1.56
The projection window shows mamo's icon and **mamo presents** on black only while preparing. The brand clears as soon as preparation finishes. There is no minimum display time, so fast preparation may finish before it becomes visible.
- The icon is included in the ZIP and offline cache. No internet connection is needed at runtime.
- A failed application load shows a reload message.
- Visuals, models and existing keyboard controls are retained from v0.1.55.
Extract All, then open **はじめに_START-HERE.html** in Chrome. Keep the operator and projection windows open.
578 checks passed in isolated Chrome on Windows. This is not physical-projector, other-PC or hardware-keyboard certification. See the bundled RIGHTS.txt for asset terms.
