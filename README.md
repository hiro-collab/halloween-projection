# Halloween Projection
WindowsでZIPを展開し、ブラウザとプロジェクターで使う投影アプリの試作です。現在は非公開で管理します。

動くコードはv0.1の技術検証版です。原VJ再現版・アプリv0.2は未完成です。
現在の表示は新規の2D全身骸骨と簡略コウモリです。3D頭/下顎・流体・背景文字・原作コウモリ/動き・分離APIは未実装。

目標:
- A: 回転ドクロ＋流体＋背景文字、頭と下顎の独立動作。
- B: 自作コウモリの飛翔＋中央文字、速度/動きの操作。
- 同じ表示面で切替。原作再現と差分確認を先に行い、その後に効率化。
- 原コウモリの画像群を再利用可能。羽ばたきまで停止させる意味ではない。
- 初回無料。将来の料金・利用条件・公開方法は未決定。

## Windowsでの取得と起動
1. GitHubのCode → Download ZIPを取得します。現在privateのためアクセス権が必要です。
2. Explorerの「すべて展開」でZIPを展開し、展開フォルダーを開きます。
3. 最上位のSTART.cmdをダブルクリックします。ブラウザーが開く設計で、起動画面は自動で閉じます。
4. 画面の「終了」を押し、終了表示を確認してからタブを閉じます。端末入力は不要です。

[日本語の短い案内](はじめに.txt)も同梱しています。
GitHub Download ZIPは開発用一式。配布候補ZIPは起動入口・HTML・案内を最上位へまとめたものです。
利用者にPython/Node/TD/PowerShell7は不要。Windows標準PowerShellを使用し、実行ポリシー変更はしません。

現在の担当環境ではExplorer/既定ブラウザー実画面を操作できず、ダブルクリック経路は未検証です。
シェル起動・HTTP/ブラウザー検証とは区別して記録します。全画面API成功とブラウザー枠除去も別判定です。
UI範囲・キー割当は仮設定。[要求仕様](docs/REQUIREMENTS.md)と区別してください。
