# Halloween Projection
WindowsでZIPを展開し、ブラウザとプロジェクターで使う投影アプリの試作です。現在は非公開で管理します。

動くコードはv0.1の技術検証版です。原VJ再現版・アプリv0.2は未完成です。
現在の表示は新規の2D全身骸骨と簡略コウモリです。3D頭/下顎・流体・背景文字・原作コウモリ/動き・分離APIは未実装。

目標:
- A: 回転ドクロ＋流体＋背景文字、頭と下顎の独立動作。
- B: 自作コウモリの飛翔＋中央文字、速度/動きの操作。
- 同じ表示面で切替。原作再現と差分確認を先に行い、その後に効率化。
- 原コウモリの画像群を再利用可能。羽ばたきまで停止させる意味ではない。
- 初回無料。将来の料金・利用条件・公開方法は未決定。

## 起動
Windowsでapp/START.cmdを実行し、コンソールを開いたままブラウザを使います。コンソールのCtrl+Cで終了。
利用者にNode/Python/TD/PowerShell7のインストールは不要です。file://直接起動は未検証です。
UI範囲・キー割当は仮設定。[要求仕様](docs/REQUIREMENTS.md)と区別してください。

## 管理
app/は技術試作、docs/は仕様・制御対応・権利・検証・収録予定、tests/は既存ブラウザ検証。
開発者はpython tools/package-preview.pyでdist/へ配布候補ZIPを作れます。Pythonは利用者の起動には不要です。
原VJ全体、未許諾モデル、原動画、会話、認証情報、私的なファイルパス、画面キャプチャを含めません。

GitHub Release・一般公開は行っていません。
