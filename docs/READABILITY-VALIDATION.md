- 実行用JS 36ファイルのASTが基点と一致。コメント、位置、文字列/数値の表記だけを除外し、式・呼出し・値・順序を比較した。

- `node tools/run-unit-tests.cjs`: CPU単体17スイートが整理前・整理後とも全通過。
- 検証用コピーで `tools/build-web-package.py` を実行。54項目・51資産を生成し、資産hashを作業ツリーと照合した。
- `sw.js` は新しい資産hash/BUILDだけを再生成し、`const SCOPE` 以降の処理は基点と同一。埋込みatlasも同一。
- Chromeの実アプリでAの描画・Pause、Q/Wの目標表示、Bへの場面切替、中断・再開・終了を確認した。Bの再開直後の画像は黒画面だったため、Bの視覚確認完了とは数えない。
- 公開済みZIPのローカル保管物は元のSHA256を保持。検証用ZIPは `output/` 内の専用コピーだけに生成した。
