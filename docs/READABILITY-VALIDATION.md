## タイムアウト調査と試験側の修正

- 前環境の一時iframe試験自体は引継ぎに含まれず、当時の直接原因の一意な再現はできない。現行試験サーバーは `frame-ancestors 'none'` と `X-Frame-Options: DENY` を返すため、同サーバーのページをiframeへ埋め込む構成は使えない。ヘッダーを緩和せず、独立したトップレベルページを使い、完了結果をPlaywrightから直接取得する試験にした。
- サーバーの許可一覧へ既存の実行資産 `usage-copy.js` を追加した。これは操作窓の案内表示用であり、製品ファイルは変更していない。
- 二窓試験でBの画像準備完了直後にPauseすると、最初の出生前の黒画面同士を比較して文字変更が失敗扱いになる場合があった。試験側で `sprite.flightTime >= 1` と粒子の存在を待ってから比較するよう修正し、53項目通過を確認した。
- 再現手順は [tests/README.md](../tests/README.md) の固定描画比較を参照。ログ・画像・解決済み試験コピーは無視対象の `output/readability-desktop/` に保存し、コミットへ含めない。
- 試験で作成したChrome窓/タブとloopbackサーバーは終了した。固定比較ランナーの終了コードはブラウザー0・サーバー2個とも0。
