# Windows起動体験 0.1.1

修正: 最上位START.cmd、日本語案内、起動画面を自動で閉じる起動処理、画面の終了から描画/所有ローカル起動処理を停止。
終了後はタブを閉じるだけ。タブを先に閉じた場合も、起動処理は応答が途絶えて90秒後に終了する。
同一originのloopbackだけを使い、Host/Originと起動ごとのランダム値を検証。外部接続・実行ポリシー変更・権限拡張なし。

全画面要求が拒否、利用不可、または成功していない場合に、パネルを戻し説明を出す。
APIのfullscreenElement、パネル非表示、実ブラウザー枠除去を別判定とする。

確認済み: GitHub標準ZIPを認証済みCLIで取得、CRC/hash、Pythonで日本語/空白フォルダーへ展開。
試験用コンソールの同一サーバー実行、Chromium154.0.8037.98のブラウザ操作19/19、
起動連携/終了/偽token/異なるOrigin/全画面失敗復帰8/8。

未確認: ブラウザーのDownload ZIP UI、Explorerの全展開/ダブルクリック、既定ブラウザーの実画面、
ブラウザー枠除去、実機投影、ダウンロード安全警告。
正規画面接続はMXC Windows platform directory HRESULT0x80070003で初期化前終了。
シェル起動/ブラウザAPI試験をUI合格としない。原VJ再現の合格とも別。
