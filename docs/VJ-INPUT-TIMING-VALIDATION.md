## Webの接続

HalloweenControlAPI.createVJ(hooks)を実レンダラー、初速/Crossスライダー、↑↓/←→、Space/Rへ接続しました。
window.halloweenVJ.apply({type:'set',key:'initialSpeed',value:1.3})が共通入口です。
初速の0..2.6は採取した0.65/1.3/2.6を含む比較範囲で、元制御の全上限を同定した値ではありません。
Crossの0..1からVortex=5−4Cross、Spiral=−1.7+0.8Cross、rotationCross=0.77(1−Cross)を渡します。
初速は誕生時だけに適用し、既存粒子の速度や羽ばたき時計を一括倍率変更しません。
既存の再生速度・羽ばたき・文字・シーンAPIも保持しました。入力フォーカス、修飾キー、反復keydownを除外します。

飛翔は24個体・寿命5秒・固定60Hzの候補積分器です。放出位置・雑音・力の適用方法・投影は原TDと未一致です。
Pause/Resumeは粒子と羽ばたきの連続状態を保持します。WebのStopは既存の「停止・解放」で、Resume時に場を作り直します。
ネイティブ計測の停止相当は状態を保持するので、両者のStopを同一挙動とは扱いません。
スマートフォンUIと通信方式は未実装です。追加サーバー・新権限を導入せず、入力契約だけを共通化しました。
