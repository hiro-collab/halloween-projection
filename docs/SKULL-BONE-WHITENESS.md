# 骨の白さ調整（未公開の検収候補）

v0.1.59 の GPU 共有化と操作案内を保持したローカル候補です。公開版への反映・Release の置換は含みません。

## 操作と保存範囲

操作窓の「ドクロの骨の白さ」で 0〜100% を連続調整します。API は `a.boneWhiteness`（数値 0〜1、初期値 0）。コウモリでは表示を隠して操作を無効にします。単窓の比較 UI では A 合成モードのときだけ有効です。専用キーは **O（アルファベットのオー）** です。色キーIの右の空き位置を使い、数字0（ドクロ数＋）とは別です。演奏開始後、操作窓にフォーカスがある間、ドクロで有効です。1押下で現在値に25ポイントを加え、100%で止まり、その次の押下で0%へ戻ります。0→25→50→75→100→0%、途中値10→35→60→85→100→0%。次の25%境界への丸めは行いません。repeatと離す前の重複keydownは無視し、入力欄・IME・修飾キー・フォーカス喪失・非表示の既存ガードを保持します。スライダーは端数を保つ連続値で、操作窓は百分率を小数2桁まで表示します。

「今の見えを基準にする」で白さも記録し、基準復帰で戻します。場面切替、Pause、Reset、中断・再表示では値を保持します。投影窓の終了後は、既存の仕様どおり文字・設定・基準を初期化します。ブラウザーを閉じた後も残す永続保存機能ではありません。

## 合成と文字

既存 stage11 の `mix(a + b, over(a, b), .824)` を保ち、文字を含まない `head + decor × (1 − .824 × headAlpha)` の寄与だけを白い骨の表示へ近づけます。未ぼかし head の被覆率を使い、最大係数は `0.65 × boneWhiteness × headAlpha` です。

完成した文字ごと白を重ねる旧候補の処理は使用しません。元の head alpha による遮蔽、文字の伝達係数、最後の Level と前景 Over を保ちます。最終 Gamma・飽和・8bit 丸めにより、骨と重なった文字の色やコントラストは変化し得ます。文字が全条件で不変になる保証ではありません。

初期値 0 は既存演算だけを通ります。流体入力、Glow、モデル、姿勢、時刻、テキスト配置、反転、円マスクは変更しません。追加の描画 pass と render target はありません。既存の GPU 共有 context、借用 dye texture と sampler、その解放順を維持します。

## 検証

`tests/browser/bone-whiteness.qa.js` は API の型・範囲、被覆内外、透明な穴、単調な白さ変化、流体入力と target 数、飽和を含む文字重なりを検査します。通常二窓操作、現行 main との 0% 画素比較、GPU 共有経路、基準復帰、JA/EN、切替・停止再開と解放は別の製品操作試験で確認します。

画像中の「文字寄与率」は同じ停止フレームで文字あり／なしの RGB 差分量を比較したもので、読める文字の割合や可読性の得点ではありません。実機投影・長時間運転・独立した外観検収は、自己試験と分けて扱います。

## Oキー追加の検証

最新の確定仕様は現在値への25ポイント加算です。25%境界への丸めは行いません。OはIの右の空きキーを使い、凡例は小画面でも収まる`+25%`、説明と読み上げは骨の白さを明記します。

CPU18スイート成功。新規O経路27、既存キー53、キャッシュ保護15、GPU/API5、キー凡例のJA/EN・390/1366px表示8の計108ブラウザー項目成功。0開始と途中値10%の循環、37.5→62.5%の端数保持、repeat/重複keydown、数字0との区別、未演奏時の受信拒否、入力・IME・Shift・Esc、Bで無効、基準保存復帰、Pause/Reset/Stop/Resume/Endを確認しました。

描画関連ファイルのhashはdcea33aと同じです。新しい性能計測や実機の物理キー／投影試験は行っていません。
