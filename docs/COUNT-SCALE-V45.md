# v45: count-triggered size presentation

Appearance is a lifecycle event, independent of input devices. A hidden slot's enter trigger resets its display multiplier/from/elapsed to0. A separate value channel advances smoothstep0→1 in0.2s. Exit retargets1→0, and removes geometry only after zero. The original standard size remains unchanged: projected local XY is multiplied around the current parent screen pivot; head/jaw world matrices, original six motion histories and model are untouched.

State: hidden → entering → visible → exiting → hidden. Repeating the same target does not restart a timer. Reversing mid-transition starts from the current multiplier, with0.2s times remaining distance, so it stays continuous and finishes in at most0.2s. At hidden completion multiplier/from/target/elapsed/duration all become0. Reentry starts fresh, increments its entry serial. Six small presentation records are bounded; hidden geometry/scratch/GPU batch count is released, while all six source motion histories deliberately keep cooking. No per-actor timer, listener or RAF is added. Dispose clears every presentation record.

Stable presentation IDs map to source phases0,2,4,1,3,5. Default3 therefore remains the adopted equally spaced0/2/4. Count changes now add/remove the tail of this fixed identity list rather than replacing survivors with a different balanced subset. At2 the two survivors are0/2, rather than v44's0/3; this preserves identity through transitions. Explicit provided poses retain caller order. Optional rows use actual rendered actor count, including outgoing actors until zero.

Pause freezes source time/orbit/jaw/solver, while the presentation channel continues on the single existing RAF until its short transition finishes, then RAF stops. A later paused edit starts from a fresh frame timestamp. Hidden document cancels RAF; resume excludes hidden wall time. Reset/new scene settles the selected count at full size and clears prior transitions; Stop/A-B/dispose releases them. Fluid feedback history is preserved when count changes; existing trails are not forcibly erased.

Verification: deterministic lifecycle/value-channel unit tests plus actual Chrome default3,1–6 UI and Q/E, zero/intermediate/full geometry, original scale product, paused matrices/source/solver, rapid reversal/spam/bulk, hidden cleanup/reentry, Reset/Stop/A-B resource release.
