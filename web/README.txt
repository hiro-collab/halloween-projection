ハロウィン投影 0.1.59 / Halloween Projection

【始め方】
1. 配布ZIPを右クリックして「すべて展開」。フォルダー全体を一緒に保持してください。
2. はじめに_START-HERE.html をChromeで開き、「映像をはじめる」を押します。
3. 「投影窓を開く」から窓を投影先へ移し、その窓で開始します。
4. 操作画面へ戻って文字を準備し、「演奏開始」を押します。
5. 終了は「投影の補正・中断・終了」→「投影を終了」です。

Windows・Chromeで動作確認しています。追加ソフトやコマンド入力は不要です。
展開した一式があればネット接続なしで使えます。プロジェクターの接続と画面配置はWindowsで設定してください。
操作画面と投影窓を開いたまま使います。投影窓を閉じると文字・設定は初期値に戻ります。

【主なキー】
1〜8：動きの激しさ / Q W E R T Y U I：色 / A S D F G H J K：文字サイズ
9 / 0：ドクロの数を減らす / 増やす（1〜6体）
Z：ドクロとコウモリを切り替える / X：投影の向きを切り替える
C：動き方を切り替える。手動の顎を自動へ戻す
L：顎の開き幅を15° / 30° / 60° / 90°から選ぶ / M：選んだ幅で開閉
V：押している間の一時アクセント（最大3秒）
B：保存した見た目の設定へ戻す（0.6秒長押し）
N：文字・設定を保ったまま映像の動きをリセット（0.6秒長押し）
Space：映像全体の一時停止・再開 / Esc：キーボード操作を止める（映像は続く）

「演奏開始」を押し、操作画面を選んだ状態で、半角英数・Shiftなしで使います。
文字入力や別の窓へ移った後、日本語入力や修飾キーを使った後は、操作画面で「演奏開始」を押し直してください。
接続が切れたら「既存の投影窓へ再接続」。投影窓を閉じた場合は、新しく開き直します。
ドクロは動き0％で定位置へ戻ります。コウモリは羽ばたきを続けるため、全体を止めるときはSpaceです。
動きを止めるときはSpace。黒い画面で中断するには「投影の補正・中断・終了」→「停止・解放」、戻すときは「再開」です。Escはキー操作だけを止めます。
詳しくは同じフォルダーのGUIDE.htmlをご覧ください。日本語 / Englishは案内だけを切り替え、投影する文字は翻訳しません。

Getting started
1. Extract the entire application ZIP and keep the folder together.
2. Open はじめに_START-HERE.html in Chrome, choose English, then Start the projection.
3. Open the projection window, move it to the projector display, and start it there.
4. Return to the console, prepare your text, and select Enable keys.
5. To finish, open Projection settings and select End projection.

Tested on Windows with Chrome. No extra software or command-line setup is needed. The extracted folder works offline.
Set up the projector connection and display arrangement in Windows. Keep both the console and projection window open.
Use 1–8 for motion, Q W E R T Y U I for color, A S D F G H J K for text size, Z to switch scenes, and Space to pause or resume.
Keys work while the console has focus. After editing text, using an input method or modifiers, or switching windows, select Enable keys again.
Space pauses motion. To blank the image, open Output, stop & exit and choose Stop & release; choose Resume to return. Esc stops keyboard controls only.
See GUIDE.html for every key, saved appearance settings and recovery steps. Changing the UI language does not translate your projected text.
Closing the projection window clears text and settings. See LICENSE.txt and RIGHTS.txt for the MIT code/artwork/data and CDmir's CC0 model.

Editing
The package includes readable HTML, CSS and JavaScript. Ordinary text and style edits need only an editor and reload.
Replacing images or models also requires updating their embedded data. Maintainer build instructions are in the source repository.
